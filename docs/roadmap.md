# Roadmap

## Phase 0 — Foundation (now)
- Repo + architecture + system design docs.
- GitHub repo creation + initial push.

## Phase 1 — MVP engine
- Canonical audit model + native YAML format.
- PDF metadata parser (read-only).
- SSH connector + check runner.
- CLI `ocli scan` with HTML report.
- 3 sample benchmarks fully converted to native audits.

## Phase 2 — Web platform
- Go API + React UI.
- PostgreSQL + Redis + MinIO.
- Asset inventory, scan jobs, dashboards.
- User/RBAC + audit log.

## Phase 3 — Breadth
- WinRM connector.
- Network device connectors.
- Nessus .audit parser.
- Cloud connectors (AWS/Azure/GCP).

## Phase 4 — Community & scale
- Plugin SDK.
- Multi-tenancy.
- Agent.
- Marketplace for audit files.
